### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                                                                                                         |
|:-----:|:-----------------------------------------------------------------------------------------------------------------------|
|   R   | Надёжность (Reliability)                                                                                               |
|  R1   | Доступность платформы 99.9%, режим работы 24/7                                                                         |
|   P   | Производительность (Performance)                                                                                       |
|  P1   | Отклик по всем операциям должен быть максимально быстрым                                                               |
|  +R   | + Ограничения (Restrictions)                                                                                           |
|  +R7  | Не повышать нагрузку на систему кредитного скоринга в рабочее время                                                    |

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Сайт/ИБ пишут в АБС, АБС раз в сутки отдаёт в конвейер. Не подходит так как будет задержка, клиент не получает быстрого решения

**Недостатки, ограничения, риски**

Возможна большая нагрузка на разные части системы, желателен переход на микросервисы + kafka для легкого масштабирования и обработки пиковых нагрузок
